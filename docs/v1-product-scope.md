# CEBench-Live 1.0 提交与评价范围

2026-10-30。1.0 为公开软件发行版本，方法规划仍为 0.2.1-planning，未验证的权重不升级为正式评分。

用户可粘贴 Chatbot 回答、文献、综述、指南与其他证据材料；也可提交公开网页和常见文件。浏览器负责文件解析，显示实际读取范围、失败与截断。不同输入共用问题清单、原文位置、来源台账和报告导出。

规则初评在浏览器运行，不上传材料。它检查可明确计算的内容及信息缺口，不能判断真实作者、检索完整性或医学正确性。

DeepSeek 深评经用户明确选择后，将解析文字和用途发送至 EOS 后台及 DeepSeek。后台识别材料类型与待核主张，查询 Europe PMC / Crossref，取得可用摘要及开放全文，并对每条主张返回来源位置和模型判断。每个来源记录取得层级，元数据不充当全文；检索失败与未得全文保持可见。模型判断与人工审定分开。

模型密钥仅由 EOS 所有者在登录后的设置中私密保存，或通过服务器环境变量配置，不能进入公开代码或报告。模型调用需要登录、主动同意和限量，服务端不保存提交文字或报告。报告由用户自行下载。服务端及模型供应商的处理政策需在选择深评前说明。

不能从文风证明某段文字由某个 Chatbot 生成。类型识别是内容推测，用户可以指定材料类别。OpenEvidence 仅作为产品参考，未取得可用授权接口前不声称已接入。没有任何已验证排行榜、独立双审、正式 GRADE 或完整检索的默认承诺。

实现依据：[DeepSeek 官方调用文档](https://api-docs.deepseek.com/quick_start/agent_integrations/)、[JSON 输出](https://api-docs.deepseek.com/api/create-chat-completion/)、[Europe PMC REST 文档](https://dev.europepmc.org/RestfulWebService)。
